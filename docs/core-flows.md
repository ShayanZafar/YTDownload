# Core flows

This file lists what a person relies on the app for, each flow with the tests that cover it at three levels: unit (one module, no network), integration (several parts together through the real routes and pipeline, outside services played by stand-ins) and UI (a real browser driving the running app), with — marking a level that has no test yet. UI tests run on stand-ins and in CI on every pull request; the browser tests tagged `@live`, which use the real YouTube, Spotify or SoundCloud, don't count. `npm run verify` checks it (`npm run core-flows`): every named test must exist and the gap count must equal Gaps allowed, which only ever goes down; see the definition of done in [CLAUDE.md](../CLAUDE.md#definition-of-done).
